METHODOLOGICAL CAVEATS
================================================================================
1. ESS is a SECONDARY descriptive summary
   - All underlying components remain separately reported
   - ESS does NOT replace component-level analysis

2. α=0.5 baseline is NOT empirically optimal
   - Equal weighting is a descriptive convention
   - No domain-specific rationale for 50-50 split
   - Sensitivity analysis shows α choice has limited practical impact

3. Components excluded from ESS:
   ✗ Faithfulness (explanation-model alignment)
   ✗ SHAP-LIME agreement (unavailable under current design)
   ✗ Perturbation robustness (different instance coverage)
   ✗ Prediction flip rate (model robustness, not explanation stability)
   ✗ Probability stability (data unavailable)

4. High component correlation (r=0.96):
   - Cross-seed Spearman and semantic stability measure similar constructs
   - ESS provides limited additional information beyond cross-seed Spearman alone
   - Consider simplifying to single primary metric in final reporting

5. Semantic stability methodology:
   - Uses corrected instance-level bootstrap (not pairwise-level)
   - Aggregates stability within semantic categories per dataset
   - Validated to retain bootstrap duplicates properly
